# Changelog

Newest first. Dates are the day the work landed.

## 2026-09-30

### Fixed

- Any web page could send requests to the local server. It now refuses any request whose Host or Origin is not itself.
- Undo could replace a file that had taken the old name. The returned file now comes back as `name 2.png`.
- Cmd+A threw a file out, Cmd+D kept one, and a held key made a decision per repeat. Cmd, Ctrl, Option and key repeat now do nothing.
- A recursive scan dropped the queued files under an unreadable subfolder. They stay queued and the folder is reported.
- A failed undo said "Put 0 back" with no reason. The reason is shown, and a retryable entry stays on the stack.
- A second copy of the app overwrote the first copy's state. A second launch now exits.
- Renaming only the case of a name was refused.
- A failed Finder label was reported as success.
- One folder or destination without a path broke every scan after it.
- The kept-list export could hand a spreadsheet a formula.
- The checks wrote into the real home folder.

### Changed

- Browse opens the normal macOS folder dialog. The in-app folder list is the fallback.
- The README image is a screenshot of the current app on generated files.

## 2026-09-02

### Added

- **Configurable quarantine.** The folder thrown-out files wait in is now set
  under *Folders and setup*, validated for existence and write access before it
  is accepted. It defaults to `~/.screenshot-triage/quarantine`.
- **Configurable star.** `W` still always keeps the file; what else it does is a
  choice between a Finder label in any of the seven colours and a mark added to
  the filename, at the front or the back. A preview shows the result against a
  real filename from the queue. The rename path reuses the existing rename
  operation, so undo handled it without new code.
- **Drag-select in the grid.** A band drawn anywhere across the tiles selects
  everything it touches. Starting the drag on an already-selected tile removes
  instead of adds, so an overshoot is corrected with the same gesture. Holding
  near an edge keeps scrolling, which a 200-tile grid needs. Shift-click takes
  the run between two tiles.
- **`G` leaves the grid**, the same key that opens it. Escape still works.
- **File counts while picking folders.** Every suggestion chip and every row in
  the folder browser shows how many reviewable files it holds, so the pile is
  visible before anything is scanned. The counts follow the Images/CSVs filter.
- **One-click folder adding.** Choosing a folder in the browser adds it directly
  rather than filling a text field that then needed a second button. Enter works
  in all three path fields.
- **Show hidden folders** toggle in the folder browser, and **Open in Finder**
  for the quarantine folder.

### Fixed

- **Changing the folder list did not change the queue.** The scan only ever added
  files; removing a folder left its files queued indefinitely. The queue is now
  defined as what the configured folders currently hold. A folder macOS refuses to
  read is the exception, since an unreadable folder is not evidence its files are
  gone.
- **Quarantined files deleted outside the app were still counted.** The header
  claimed files that were not there and the empty-quarantine button would have
  failed on every one. Reconciled at startup rather than only on a scan.
- **A quarantine folder inside a scanned folder fed itself back into the queue.**
  Scan exclusions covered only the app directory, which stopped being sufficient
  once quarantine became configurable.
- **A folder holding nothing but `.DS_Store` counted as occupied**, because
  `os.listdir` returns dotfiles. This pinned existing installs to the old
  quarantine location.
- **Clicking a grid tile stopped selecting it** during the drag-select work.
  `setPointerCapture` retargets later pointer events to the capturing element, so
  the tile has to be captured on pointerdown rather than read at pointerup.

### Changed

- **Quarantine moved out of the app directory.** It previously defaulted to
  `data/quarantine` inside the checkout, where `git clean -xfd` ignores
  `.gitignore` and would destroy files the app promises to keep. Existing installs
  stay where they are while the old folder still holds anything.
- **Images are cacheable.** `Cache-Control: no-store` meant every grid redraw and
  every revisited card re-read and re-decoded from disk. Images now carry an ETag
  derived from the file's own modification time and size, with `max-age` and 304
  responses.
- **Grid tiles use thumbnails.** A 480px JPEG generated by `sips` and cached on
  disk, keyed by the source file's mtime and size, roughly a twentieth of the
  bytes of the original. Falls back to the original where `sips` is unavailable.
- **The card view prefetches** the next few images.
- The browse panel moves to sit under whichever row opened it, instead of always
  living in the first card a full screen away.

### Tests

Grown from 14 checks to 25, covering the quarantine configuration, star modes and
their undo, folder-list changes, the denied-folder exception, and the
self-rescanning quarantine case.

## 2026-08-27 - UI refinement pass

A refinement inside the existing direction: no layout restructured, no feature
added or removed, no route or function renamed. One file changed,
`static/index.html`.

### Changed

- **One scale instead of thirteen.** Thirteen distinct raw border radii became
  five tokens plus `50%` for circles. Twenty font sizes became an eight-step
  scale with one deliberate literal left. Two near-identical spring curves
  collapsed into one token, and ten transition durations became five. Spacing
  normalised to 4px steps.
- **The four action buttons** dropped a flat bottom lip that read as a keycap on
  a rectangle and a smudge on a circle, in favour of real elevation. All three
  secondary buttons now hover consistently; Throw out previously had no hover
  state at all.
- **Key hints stopped being four more boxes.** `A or ←` was a 9px mono label in
  its own bordered mini-keycap, under a circle, under a photo. Now plain mono.
- **The tally stopped printing zeroes.** `8 to go · 0 kept · 0 filed · 0 out`
  became `8 to go`, each counter appearing once it has a number.
- **`age()` stopped saying the date twice.** `21 days ago, Aug 6, 2026` became
  `21 days ago`, with the absolute date taking over past 30 days.
- **Grid tile names truncate from the left**, since every screenshot begins
  `Screenshot 2026-0…` and right-truncation said nothing.
- **The grid heading lost its wrapper panel**, a bordered card containing only a
  heading and one line.
- One keycap treatment across the three places a key is drawn as an object.

### Fixed

- **The browse panel's own buttons were unreachable.** They sat inside a 240px
  scrolling box and fell off the bottom of it on any real home folder.
- **Disabled action buttons rendered as fully live**, despite being `disabled` in
  the DOM.
- **Hover and selected were the same fill** in the destination picker, so pointing
  at a row looked like having already aimed at it.
- **Paths broke mid-word everywhere.** `word-break: break-all` split folder names
  in half; `overflow-wrap: anywhere` breaks only where a line runs out.
- **Shortcut labels started at four different x positions**, because rows carry
  one, two or three keycaps. Fixed-width key column added.
- **`border-radius` was being set inside a `:focus-visible` rule**, reaching any
  focused element that did not declare its own.
- **Bulk buttons had no border**, rendering as flat shapes on a flat bar.

### Left alone, deliberately

- The palette, typography and the swipe-stamp system. That is the direction.
- The card-stack peek, image pre-decode, stage guard, optimistic advance and the
  transitionend-plus-safety-net settle. Load-bearing and documented; a visual pass
  has no business inside them.
- The `include subfolders` checkbox appearing both below the add row and on each
  added row. Genuinely confusing, but the two mean different things and changing
  either would change behaviour.
